# Jump Game Web 🎮

A simple browser-based jump game built using HTML, CSS, and JavaScript.  
The player jumps over obstacles, scores points, and the difficulty increases over time.

---

## 🚀 Features
- Jump-based gameplay using keyboard controls
- Increasing difficulty as the score increases
- Obstacle generation and collision detection
- Score and high score tracking using localStorage
- Clean UI with basic animations
- Structured JavaScript using classes

---

## 🕹️ How to Play
- Press **Space** to jump
- Avoid hitting obstacles
- Press **P** to pause or resume the game
- Try to beat your high score

---

## 🛠️ Tech Stack
- HTML5 (Canvas)
- CSS3
- JavaScript (ES6)
